# Student Management System

A command-line Student Management System built with Python, Object-Oriented Programming (OOP), and SQLite.

## Features

- Add student records
- Display all students
- Search students by ID
- Update student marks
- Delete student records
- Validate student input
- Prevent duplicate student IDs
- Store records persistently using SQLite

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- SQLite
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/kellasravanthi/student-management-system.git
   ```

3. Open the project directory:

   ```bash
   cd student-management-system
   ```

4. Run the Student Management System:

   ```bash
   python3 database_practice.py
   ```

The SQLite database is created locally when the program runs.
